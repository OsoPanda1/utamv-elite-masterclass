# Epistemología UTAMV

## Postura

UTAMV adopta una epistemología pragmática-sistémica.

El conocimiento es considerado válido cuando:

1. Explica coherentemente el comportamiento del sistema.
2. Produce capacidad predictiva suficiente.
3. Puede ponerse a prueba mediante intervención.
4. Genera aprendizaje documentado y transferible.

## Diferenciación

| Modelo | Supuesto |
| --- | --- |
| Bootcamp táctico | Saber ejecutar herramientas |
| MBA marketing | Optimizar procesos comerciales |
| UTAMV | Diseñar sistemas adaptativos medibles |

## Criterio de verdad

En UTAMV ninguna afirmación estratégica se considera válida
sin triangulación entre:

- observación sistémica,
- evidencia EOCT,
- iteración documentada.
