# Glosario Institucional UTAMV

## Léxico epistemológico-operativo del ecosistema TAMV / Método 4L

### Propósito
Este glosario define lenguaje oficial para garantizar coherencia conceptual,
operativa y narrativa entre formación, investigación, implementación y defensa.

### Principios
1. Precisión antes que ornamentación.
2. Simplicidad con profundidad.
3. Todo término debe ser operativo.
4. Pensamiento sistémico como base lingüística.

### Estructura de definición
- Técnica
- Conceptual
- Filosófica
- Operativa
- General

## Núcleo fundacional
### TAMV
Marco sistémico para diseñar, gobernar y evolucionar ecosistemas resilientes.

### Método 4L
Landscape, Leverage, Loop y Learn como ciclo cognitivo-operativo.

### EOCT
Matriz de evidencia Económica, Operativa, Científica y Transaccional.

### A.P.E.X.
Análisis, Práctica, Evidencia y Expansión como gramática pedagógica.

## Roles institucionales
- Operador: ejecuta tareas con criterio.
- Diseñador: modela estructuras y flujos.
- Arquitecto: diseña sistemas integrales.
- Centinela: audita deriva y coherencia.

## Máximas
- Diseñar antes de ejecutar.
- Medir antes de concluir.
- Documentar antes de escalar.
- Comprender antes de automatizar.
- Construir activos antes que dependencia.
- Aprender antes que repetir.
