# Principios de ejecución UTAMV

## 1. Diseñar antes de ejecutar
Toda acción táctica debe responder a una arquitectura explícita.

## 2. Medir antes de concluir
Toda hipótesis requiere evidencia EOCT.

## 3. Documentar antes de escalar
No se replica lo no comprendido.

## 4. Construir activos propios
Toda dependencia debe justificarse.

## 5. Aprender por iteración
El error documentado es insumo metodológico.

## 6. Pensar en legado
Todo proyecto debe dejar capacidad instalada.
