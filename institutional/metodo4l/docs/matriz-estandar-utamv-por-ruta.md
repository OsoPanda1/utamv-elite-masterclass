# 📦 MATRIZ ESTÁNDAR UTAMV POR RUTA

## Sistema de Diseño Modular · TAMV + 4L + A.P.E.X. + EOCT

---

## 0. PRINCIPIO ESTRUCTURAL

Cada ruta UTAMV es un **sistema replicable de formación aplicada**, compuesto por módulos homogéneos que mantienen la misma gramática operativa:

> TAMV diseña la arquitectura del sistema  
> 4L ejecuta la dinámica de intervención  
> A.P.E.X. consolida aprendizaje verificable  
> EOCT valida impacto multidimensional

Cada módulo es una **unidad completa de transformación**, no una lección aislada.

---

## 1. ARQUITECTURA BASE POR RUTA

Cada ruta debe contener la siguiente estructura obligatoria:

```text
/ruta
   /00-mapa-de-ruta.md
   /modulos/
   /ejercicios/
   /rubricas/
   /plantillas/
   /casos/
   /guia-facilitador/
   /eoct-dashboard/
```

---

## 2. MAPA DE RUTA (ESTRUCTURA FIJA)

Toda ruta UTAMV sigue esta progresión universal:

### MÓDULOS ESTÁNDAR

```text
M0 · Inducción UTAMV (marco mental + sistema completo)
M1 · Epistemología aplicada a la ruta (cómo se piensa el sistema)
M2 · TAMV aplicado al dominio (arquitectura del sistema real)
M3 · Método 4L (dinámica operativa de intervención)
M4 · A.P.E.X. (aprendizaje en acción + evidencia)
M5 · EOCT (medición e impacto multidimensional)
M6 · Proyecto integrador + defensa + legado institucional
```

---

## 3. MATRIZ POR MÓDULO (ESTÁNDAR UNIVERSAL)

Cada módulo debe replicar EXACTAMENTE esta estructura:

```text
/modulos/MX-nombre/
   - README.md
   - lecciones/
   - guia-facilitador.md
   - entregables/
   - ejercicios/
   - evaluacion-eoct.md
   - checklist-apex.md
```

---

## 4. ESTRUCTURA DE LECCIONES (DENTRO DE CADA MÓDULO)

Cada módulo contiene lecciones con el siguiente patrón:

```text
MX.L1 · Título operativo
MX.L2 · Título operativo
MX.L3 · Título operativo
...
```

Cada lección incluye:

- Objetivo observable
- Relación TAMV
- Dinámica 4L aplicada
- Evidencia A.P.E.X.
- Métrica EOCT activada
- Entregable mínimo

---

## 5. GUÍA DE FACILITADOR (ESTÁNDAR GLOBAL)

Cada módulo incluye una guía con esta estructura fija:

- Propósito del módulo (1–2 líneas operativas)
- Rol dentro del sistema UTAMV
- Conexión con axiomas institucionales
- Secuencia didáctica (bloques operativos)
- Errores típicos del alumno
- Activadores 4L por sesión
- Criterios EOCT observables

---

## 6. EJERCICIOS (SISTEMA UNIFICADO)

Todos los ejercicios deben derivarse de 4 tipos base:

- Landscape Worksheet (lectura del sistema)
- Leverage Matrix (detección de palancas)
- Loop Simulator (dinámica causa–efecto)
- Learn Protocol (reglas operativas derivadas)

---

## 7. RÚBRICAS (ESTÁNDAR EOCT)

Cada evaluación sigue esta escala:

### NIVEL 1
Operación táctica sin estructura sistémica

### NIVEL 2
Aplicación parcial de 4L sin trazabilidad completa

### NIVEL 3
Sistema completo aplicado + evidencia EOCT en ≥2 dimensiones

### NIVEL 4
Sistema + evidencia + legado institucional reutilizable

---

## 8. PLANTILLAS DE ENTREGABLES (GLOBAL)

Todas las rutas usan las mismas plantillas base:

```text
entregable-4l.md
informe-eoct.md
readme-sistema.md
protocolo-legado.md
```

Cada una debe contener:

- Landscape
- Leverage
- Loop
- Learn
- EOCT (E/O/C/T)
- Legado reutilizable

---

## 9. CASOS DE APLICACIÓN

Cada ruta debe incluir:

- 1 caso canónico transversal (ej: Netflix/Qwikster)
- 2–3 casos específicos de la industria de la ruta
- 1 caso real desarrollado por alumno

Todos deben ser analizados con:

```text
4L + EOCT + lectura TAMV
```

---

## 10. CAPA A.P.E.X. (ESTRUCTURA UNIVERSAL POR MÓDULO)

Cada lección dentro de cada módulo se encapsula en:

- Audio 1 · Entrada cognitiva (contexto + sistema)
- Audio 2 · Fricción cognitiva (contraste + activación)
- Audio 3 · Integración operativa (acción + transferencia)

---

## 11. EOCT (CAPA DE VALIDACIÓN)

Toda ruta debe consolidar un dashboard con:

- E · Económico
- O · Operativo
- C · Científico
- T · Transaccional

Regla:

> Ninguna mejora es válida si deteriora críticamente otra dimensión.

---

## 12. PRINCIPIO DE CONSISTENCIA

Todas las rutas comparten la misma gramática estructural:

- Cambia el dominio
- NO cambia el sistema

---

## 13. RESULTADO DEL SISTEMA

Cada ruta UTAMV debe producir:

- operadores → arquitectos de sistemas
- conocimiento → protocolos reutilizables
- aprendizaje → evidencia medible
- experiencia → legado institucional
