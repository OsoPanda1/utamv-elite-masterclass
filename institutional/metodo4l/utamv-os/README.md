# UTAMV OS v1.0

Sistema operativo educativo versionable para convertir aprendizaje en arquitectura aplicable.

## Principio base
UTAMV OS no es un LMS ni un curso lineal. Es un sistema ejecutable que debe:
- definir sistema
- ejecutar aprendizaje
- medir comprensión
- generar evidencia
- producir legado reutilizable

## Estructura
- `manifest/`: supuestos, epistemología, principios.
- `core/`: TAMV, 4L, A.P.E.X., EOCT.
- `engine/`: loop de aprendizaje, evaluación, riesgos.
- `system/`: schemas, versionado, convenciones, checklist de sesgos.
- `routes/`: rutas especializadas por dominio.
- `saas-layer/`: arquitectura objetivo de producto.
- `assets/`: diagramas, audios y templates.
- `docs/`: changelog, glosario, quickstart.

## SemVer educativo
- MAJOR: cambios estructurales en TAMV/4L/APEX/EOCT.
- MINOR: nuevas rutas/módulos.
- PATCH: correcciones y claridad.
